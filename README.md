# KORbuild Finances

Primeiro protótipo navegável do KORbuild Finances.

## Conceitos da v1.0
- Objetivo → Estratégias → Aportes/Rateio → Realizado → Patrimônio → Projeção
- Controle de receitas e despesas
- Orçamento planejado × realizado
- Patrimônio separado de fluxo financeiro
- Investimentos como instrumentos patrimoniais
- Cenários sem alterar a realidade
- Fatores que podem ajudar ou atrapalhar a trajetória
- Dashboard: objetivo primeiro, patrimônio, evolução, dinheiro e detalhes
- Patrimônio inicial do objetivo pode ser R$ 0
- Valores e premissas exibidos são ilustrativos para prototipação

## Estrutura
- `index.html` — aplicação/protótipo navegável
- `styles.css` — estilos
- `app.js` — navegação e interações básicas

## Status
Protótipo UX/fluxo. Ainda sem autenticação real, Supabase, persistência ou motor financeiro produtivo.
